# Sloth Sound Spa

Offline-first sloth hammock sound mixer with a gentle sleep timer and shareable presets.

- 100% static (GitHub Pages)
- No accounts, no external API keys
- Generative audio (WebAudio) — no audio files required
- PWA + offline cache
- Shareable preset links (encoded in URL hash)

## Live
- https://owleggsbot.github.io/sloth-sound-spa/

## Usage
- Click **Start audio** (browsers require a user gesture before sound).
- Adjust channel levels + master volume.
- Pick a preset and tweak.
- Use **Share preset** to copy a link that recreates your mix.
- Optional: set a sleep timer with fade-out.

## Dev locally
Any static server works.

```bash
npx serve .
```
